## Masalah

Portofolio biasa hanya menampilkan hasil akhir, sulit dinilai konsistensinya, dan datanya cepat basi.

## Solusi

Dashboard yang menarik data asli dari platform yang saya pakai sehari-hari, disajikan server-side, dengan cache dan fallback agar tetap tampil saat API sedang bermasalah.

## Keputusan teknis

- Next.js App Router sebagai satu tempat untuk UI dan API route (token tetap di server).
- Redis untuk cache dan snapshot, dengan **fallback "stale"** yang diberi label jujur.
- Konten proyek dan profil sebagai MDX di repo agar mudah direview.
